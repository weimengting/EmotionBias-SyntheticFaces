# EmotionBias-FaceGen

This repository contains the code and resources for the paper:

**"Happy Young Women, Grumpy Old Men? Emotion Prompts as Demographic Selectors in AI Image Generation"**  
Mengting Wei, Aditya Gulati, Guoying Zhao, Nuria Oliver  

---

## 📌 Overview

Synthetic faces generated by text-to-image (T2I) models are increasingly used in advertising, journalism, and social media. However, their demographic biases under emotionally conditioned prompts remain insufficiently understood.

In this project, we conduct a systematic audit of demographic biases in synthetic face generation across multiple T2I models. Specifically:

- We evaluate **8 T2I models** (4 Western and 4 Chinese)
- Generate **56,000 synthetic faces** under **7 prompt conditions** (6 emotions + 1 neutral baseline)
- Estimate demographic attributes (gender, race, age, attractiveness) using **FairFace** and a ResNet-based attractiveness classifier
- Quantify bias using **information-theoretic divergence metrics** (KL, JS, TVD)
- Compare against:
  - Global population statistics (UN World Population Prospects 2024)
  - Neutral-prompt baseline per model

### 🔍 Key Findings

- All models exhibit **strong demographic representation biases**
- **Young individuals (20–39) are heavily over-represented** (>80% in 6 of 8 models), while older adults are largely absent
- **Negative emotions amplify biases**, consistently shifting outputs toward older, White-coded, and male-coded faces
- The **young × female × Black** intersection appears at only 1.3% on average (suppression factor 0.25×)
- **Happiness shows the least demographic shift**
- Western and Chinese models show **broadly similar bias patterns** despite different development contexts

These findings highlight the importance of **intersectional, emotion-conditioned, and multilingual bias auditing** before deploying generative models.

## 📊 Dataset

The generated dataset (56,000 synthetic faces) and corresponding annotations are available at:

👉 [mengtingwei/emotion_bias](https://huggingface.co/datasets/mengtingwei/emotion_bias)

The dataset includes:
- 1,000 images per model per condition (8 models × 7 conditions)
- Demographic annotations: gender, race, age, attractiveness
- Model source (Western / Chinese)
- Metadata for analysis
