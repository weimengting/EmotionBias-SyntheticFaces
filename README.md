# EmotionBias-FaceGen

This repository contains the code and resources for the paper:

**"Happy Young Women, Grumpy Old Men? Emotion-Driven Demographic Biases in Synthetic Face Generation"**

---

## 📌 Overview

Synthetic faces generated by text-to-image (T2I) models are increasingly used in advertising, journalism, and social media. However, their demographic biases under emotionally conditioned prompts remain insufficiently understood.

In this project, we conduct a systematic audit of demographic biases in synthetic face generation across multiple T2I models. Specifically:

- We evaluate **8 T2I models** (4 Western and 4 Chinese)
- Generate **56,000 synthetic faces** under **6 emotion conditions**
- Estimate demographic attributes (e.g., gender, race, age, attractiveness) using **FairFace**
- Quantify bias using **information-theoretic divergence metrics**
- Compare against:
  - Global population statistics
  - Neutral-prompt baseline

### 🔍 Key Findings

- All models exhibit **demographic representation biases**
- **Young individuals are over-represented**, while older adults are largely absent
- **Negative emotions amplify biases**, shifting outputs toward:
  - Older
  - White
  - Male faces
- **Happiness shows the least bias shift**
- Western and Chinese models show **similar bias patterns**

These findings highlight the importance of **emotion-conditioned and intersectional bias auditing** before deploying generative models.

- Metadata for analysis
